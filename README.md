# Exchange Rate Forecasting

## Project Description

This project predicts exchange rates using Time Series Forecasting techniques.

The models used are:
- ARIMA
- Exponential Smoothing

## Dataset

- File: `exchange_rate.csv`
- Contains Date and Exchange Rate values.

## Libraries Used

- pandas
- numpy
- matplotlib
- seaborn
- statsmodels
- scikit-learn

## Steps Performed

1. Load the dataset.
2. Convert the Date column to datetime.
3. Plot the exchange rate data.
4. Handle missing values.
5. Build the ARIMA model.
6. Forecast future exchange rates.
7. Build the Exponential Smoothing model.
8. Compare both models using RMSE.

## Output
- Time Series Plot
- ACF & PACF Plots
- Forecast Graphs
- RMSE Comparison
